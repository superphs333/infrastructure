# 보안 지침

[← README로 돌아가기](../README.md)

## 관리 UI

- Nginx Proxy Manager 관리 UI는 공개 인터넷에 직접 노출하지 않는다.
- 관리용 `81`번 포트는 `0.0.0.0`이 아닌 `127.0.0.1`에만 바인딩한다.
- 관리 UI에는 SSH 터널을 통해 접속한다.
- VPN이나 내부망을 통한 직접 공개 또는 관리 도메인 프록시는 별도 보안 정책을 정한 뒤 검토한다.

관리 UI 접속 방법은 [운영 가이드](operations.md#관리-ui-접속)를 확인한다.

## 서비스 네트워크

- 외부 요청을 받아야 하는 웹 컨테이너만 `proxy-nw`에 연결한다.
- DB와 Redis는 `proxy-nw`에 연결하지 않고 서비스 내부 네트워크에만 둔다.
- 서비스별 내부 네트워크를 사용해 다른 서비스의 컨테이너와 격리한다.

네트워크 구성에 관한 자세한 내용은 [아키텍처 문서](architecture.md#docker-네트워크-구성)를 확인한다.
